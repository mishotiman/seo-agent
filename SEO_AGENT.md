## Task Description

Build an **SEO audit agent** that can audit a single page or an entire website from a URL.
Use any agent framework you like. The agent's model should be swappable through
configuration, without changes to the agent logic. Decide deliberately which checks
belong in code and which need model judgement. Keep the crawl bounded and the
output structured.

## Deliverables

- The agent (a repository, zip or exported workflow) with instructions covering
  setup, how to run it, and how to switch the model.
- A short explanation of your design decisions: which checks you run in code and
  which rely on the model, how you bound the crawl, and how you structured the
  output.
- A proposal for how you would evaluate the agent's quality.

## Evaluation Criteria for Task

- Soundness of the design decisions, and how well you explain their pros and
  cons.
- How clearly the setup is communicated, and how realistic it is.
- Rigour of the evaluation approach.
- Ability to find and use the relevant information in the data.
- Strength of the argument behind your recommendation, and clarity of how you
  communicate it.
