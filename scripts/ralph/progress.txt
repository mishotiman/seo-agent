## Codebase Patterns
- Use `.venv/Scripts/python.exe -m mypy` (strict, files=src) and `.venv/Scripts/python.exe -m pytest -q` for checks
- Web UI lives in `src/seo_audit/web/` (`create_app()` in `__init__.py`, CLI in `server.py`, static files in `static/`); tests in `tests/test_web.py`
- CLI uses typer; `seo-audit-ui` reuses typer via `typer.run(serve)`
- Web API errors are always `JSONResponse({"detail": str}, status)` via `_detail()` in `web/__init__.py`; endpoints that can return it use `response_model=None`
- Web tests that need a background job to outlive a request must use `with TestClient(app) as client:` (single event loop); a bare TestClient runs each request in its own loop and kills the task
