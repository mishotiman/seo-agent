## Codebase Patterns
- Output models live in `src/seo_audit/schema.py`; after editing them run `.venv/Scripts/python -m seo_audit.schema` to regenerate schema/audit-report.schema.json
- Python venv at `.venv`; run tools via `.venv/Scripts/python -m pytest` and `.venv/Scripts/python -m mypy` (strict, pydantic plugin; checks `src`)
- Source in `src/seo_audit/`, tests in `tests/`; package installed editable (`pip install -e .`)
- Config: `load_config(path, env)` in config.py; env overrides use `SEO_AUDIT_<KEY>` and `SEO_AUDIT_<SECTION>__<KEY>`; raises `ConfigError`
- CLI tests monkeypatch `cli._make_client` / `cli._make_llm` with a MockTransport client and a fake-completion LLMClient (see tests/test_audit.py)
- Markdown snapshot lives in tests/snapshots/report.md; regenerate with `UPDATE_SNAPSHOTS=1 .venv/Scripts/python -m pytest tests/test_report.py`
- Use `python`-less shells: on this machine call `py` (python.exe not on PATH)
